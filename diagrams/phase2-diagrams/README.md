## How to use
- **Edit:** open https://excalidraw.com and drag in a `.excalidraw` file (or use the Excalidraw VS Code extension / Obsidian plugin).
- **View or embed:** the `.svg` files open in any browser and can be embedded in a README, wiki, or GitHub Pages site: `![Overview](svg/00-overview.svg)`.
- **Gallery:** `manifest.json` lists every diagram with title and file paths, ready for a gallery page to read.

The SVGs are clean-style previews generated from the same layout; the `.excalidraw` files keep the hand-drawn look and are the source to edit.
